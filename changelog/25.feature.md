Added the read paths for records, drafts, metadata and citations:

- `ZenodoClient.get_published` and `ZenodoClient.get_draft`,
  which read a published record and a record's draft respectively.
  Neither guesses which of the two you meant,
  so asking for one specifically is possible.
- `ZenodoClient.get_record`, for when you do not already know which you have.
  It works it out — the published record if there is one, otherwise the draft —
  and the record it hands back says which you got,
  through its `is_draft` and `is_published` fields.
- `ZenodoClient.get_metadata`, and `retrieve_metadata`,
  which also do not need to be told which it is.
  A published record can also have a draft holding metadata changes
  which have not been published yet;
  in that case you get the published metadata, not the pending changes,
  and `get_draft` is how to see the latter.
- `ZenodoClient.get_parent_id`, the ID which refers to all versions
  of a record and resolves to whichever is the latest at the time.
- `ZenodoClient.get_citation`, and `retrieve_citation`.

Records come back in Zenodo's native InvenioRDM serialisation,
rather than the legacy-compatible shape it serves by default,
so `access`, `pids`, `parent` and `versions` are all there.
`get_metadata` returns the contents of the record's `metadata` key,
i.e. exactly what `update_metadata` takes,
so metadata can be read off one record and applied to another
without unwrapping anything.
Note that this is the InvenioRDM metadata schema,
which is a breaking change from the schema the legacy API used.

Citations can be had in any format Zenodo exports,
see `CitationFormat`: BibTeX (the default), CSL, DataCite JSON and XML,
Dublin Core, JSON-LD, MARCXML, DCAT,
and a styled, human-readable citation string.
The styled string takes a `style` and a `locale`;
these are ignored, with a warning, for every other format.

Zenodo wants full CSL style IDs, not the short names its web UI shows,
so `--style mla` is the obvious thing to ask for and it does not work.
Styles we have verified Zenodo rejects now raise
`openscm_zenodo.exceptions.UnknownCitationStyleError` before the request,
naming the ID which does work.
Styles we have not checked are sent anyway, with a warning:
Zenodo accepts more CSL styles than `KNOWN_CITATION_STYLES` lists,
so refusing them would be us getting in the way.
Pass `warn_unknown_style=False` if you are using a style you know works
and would rather not hear about it on every call.

The pre-InvenioRDM `retrieve_metadata` is now `retrieve_metadata_legacy`,
so the new one can take the name.
It goes when the command-line interface is trimmed.
