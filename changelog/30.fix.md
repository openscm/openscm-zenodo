Fixed `openscm-zenodo --logging-config FILE`, which raised
`TypeError: LoguruConfig.load() missing 1 required positional argument` for every
configuration file rather than applying it.

`loguru-config` is an optional extra and was in no test group, so nothing
exercised this path. It is now a test dependency and the flag is covered, both
through `setup_logging` and through the command line.
